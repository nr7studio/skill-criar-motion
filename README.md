# criar-motion

Skill do curso **Motion com Claude**, por Naamã Rodrigues (NR7 Studio).

Cria motion graphics profissional com Remotion, em 3 etapas com a sua aprovação em cada uma:

1. Storyboard estático para aprovar a estética
2. Animação com preview no Remotion
3. Exportação em MP4 (só quando você pedir)

Antes de começar, a skill faz as perguntas sobre texto, formato, duração, estilo, cores e áudio.

## Como instalar

Copie o texto abaixo, cole no seu Claude e envie:

```
Instale esta skill no meu Claude: https://github.com/nr7studio/skill-criar-motion
```

## Como usar

No Claude, marque a skill **criar-motion** e diga o motion que você quer criar.
