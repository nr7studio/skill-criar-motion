# criar-motion

Skill do curso **Motion com Claude**, por Naamã Rodrigues (NR7 Studio).

Cria motion graphics profissional com Remotion, em 3 etapas com a sua aprovação em cada uma:

1. Storyboard estático para aprovar a estética
2. Animação com preview no Remotion, com efeitos sonoros se você quiser
3. Exportação em MP4 (só quando você pedir)

Antes de começar, a skill faz as perguntas sobre texto, formato, duração, estilo, cores, áudio e efeitos sonoros.

## Baixar

- Arquivo da skill: [criar-motion.skill](https://github.com/nr7studio/skill-criar-motion/raw/main/criar-motion.skill)

## Instalar

No Claude, abra Configurações > Skills (ou Capacidades) e envie o arquivo `.skill`.

Se preferir, copie o texto abaixo, cole no seu Claude e envie:

```
Instale esta skill no meu Claude: https://github.com/nr7studio/skill-criar-motion
```

## Como usar

No Claude, marque a skill **criar-motion** e diga o motion que você quer criar.

## Efeitos sonoros

Sempre destas 3 fontes: [Openverse](https://openverse.org) (só CC0), [Real SFX](https://github.com/Clipwing/skills/tree/main/skills/real-sfx) e [Earshot](https://github.com/Leonxlnx/earshot).
